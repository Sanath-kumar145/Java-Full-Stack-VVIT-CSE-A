DataTypes: 
-----------
    ->DataTypes represent the what of data we are storing on that variable 

    Types: 
        1. Primitive  DataTypes 
            i. number 
            ii.string 
            iii. boolean 
            iv . null 
            v. undefine 
            vi. symbol 
            vii. bigint


        2. Non Primitive  DataTypes
            i. Arrays
                ->Arrays are the linear data structures used to store collection of homogenous or heterogenous data 

                In JS Arrays Declaration : 
                --------------------------
                    1. literal way 
                    2. using new keyword (object)

                    Loops : 
                    -------
                        1. for loop 
                        2. while loop 
                        3. do while loop 
                        4. for-of loop (arrays / strings) ->only values
                        5. for-in loop (arrays / strings) ->only index's 
                        6. forEach loop 


                        7. map()
                        8. filter()
                        9. reduce()



            ii.Objects
                ->Objects are the real time entities used to store data in the from key and value pair  
                In JS Objects Declaration : 
                --------------------------
                    1. literal way 
                            Syntax: 
                                    variableType variableName={
                                                    key1:value,
                                                    key2:value 
                                                }


                    2. using new keyword (object)
                            Syntax: 
                                    variableType variableName=new Object({
                                                    key1:value,
                                                    key2:value 
                                                })

            iii.functions
                ->functions are the block of statements which will get execute when ever it called 

                Notes: 
                    ->Using functions we can perform Code reusability
                    ->And Also increase Code readability 

            Types: 
            -------
                1. User Define functions 
                2. Predefine functions
